# Protocol

REST GET /api/health -> {"status":"UP","service":"randomconnect"}.
WebSocket /ws: JSON {type, requestId?, roomId?, payload?}. Guest identity belongs to the socket, never to a client senderId.

Client: FIND_PARTNER, NEXT_PARTNER, LEAVE_ROOM, CHAT_MESSAGE, WEBRTC_OFFER, WEBRTC_ANSWER, ICE_CANDIDATE, PING, PONG.
Server: SESSION_READY, WAITING, MATCH_FOUND, ROOM_CLOSED, PARTNER_LEFT, CHAT_MESSAGE, WEBRTC_OFFER, WEBRTC_ANSWER, ICE_CANDIDATE, ERROR, PONG.
MATCH_FOUND payload: partnerId, initiator (exactly one true). Waiting peer initiates.
Chat payload.text is trimmed (1–2000 characters); server adds messageId, senderId, sentAt and echoes once to both members (sender uses echo, no optimistic duplicate).
SDP payload.sdp = {type: offer|answer, sdp: string}. ICE payload.candidate = {candidate: string, sdpMid?, sdpMLineIndex?}.
Relay requires current exact room membership. NEXT_PARTNER / LEAVE_ROOM carry roomId when matched; stale lifecycle commands cannot close a new room. Duplicate FIND is idempotent. Stop while waiting needs no roomId.
ERROR payload: code, message (safe static text). Codes: INVALID_MESSAGE, NOT_IN_ROOM, RATE_LIMITED, ALREADY_MATCHED, INTERNAL_ERROR.
Maximum envelope 64 KiB characters (container closes above 128 KiB); text 2000 characters; SDP 48000 characters; ICE 4096. Rate per socket: 1200 envelopes per 10 seconds and 10 matchmaking/Next or 30 chat messages per 10 seconds. Heartbeat client PING every 15 sec, server expires after 45 sec of inactivity (scan every 5 sec).
Room close returns ROOM_CLOSED to requester, PARTNER_LEFT to peer; peer returns IDLE and does not requeue. The waiting set is randomized among eligible waiting peers when there is a choice.

SESSION_READY and MATCH_FOUND include payload.iceServers generated by the server. Without TURN env only STUN is returned; TURN credentials expire in 600 seconds and are refreshed on each match. Client heartbeat also abandons a silent socket after approximately 45–60 seconds. CHAT_MESSAGE echo is delivered to both members once; UI uses messageId to suppress duplicates.
